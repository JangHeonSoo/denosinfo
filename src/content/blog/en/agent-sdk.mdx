Everyone keeps saying "agents, agents." Drop into the code and most of it is fog. OpenAI's Agents SDK, released on March 11, 2025, turned a chunk of that fog into solid ground. It's light. Almost no abstractions. Python, as-is.

## So what does it actually do

The Agents SDK is a Python framework for attaching tools, guardrails, and handoffs to LLMs so they can "decide and act" on their own. It's the production-ready successor to OpenAI's earlier experiment, Swarm. No LangChain-sized cathedral here. Just a handful of primitives: Agent, Runner, Tool, Handoff, Guardrail, Session.

Quick disambiguation. OpenAI also ships a consumer feature named "ChatGPT agent" - the one you trigger with `/agent` in the composer to have it browse the web for you. That's not this. This piece is about the developer SDK.

## Six core concepts

| Concept | One-liner |
|---|---|
| Agent | An LLM bundled with instructions, tools, and a model |
| Runner | The thing that actually runs the agent |
| Tool | A Python function decorated with `@function_tool` |
| Handoff | A special tool that transfers control to another agent |
| Guardrail | Parallel input/output validation that halts on failure |
| Session | Automatic conversation history (e.g., SQLiteSession) |

## Install

Three things: Python 3.10+ (the repo allows 3.9+), a virtualenv, and an OpenAI API key.

```bash
python -m venv .venv
source .venv/bin/activate # Windows: .venv\Scripts\activate
pip install openai-agents
```

`uv` users get a shorter line.

```bash
uv add openai-agents
```

Need voice? `pip install "openai-agents[voice]"`. Redis sessions? `pip install "openai-agents[redis]"`. Pick what you need.

Set the key.

```bash
export OPENAIAPIKEY="sk-..."
```

## First run - Hello, Agent

Five lines and it moves.

```python
from agents import Agent, Runner

agent = Agent(
 name="Assistant",
 instructions="You are a helpful assistant. Keep replies short.",
)

result = Runner.run_sync(agent, "Write a haiku about recursion.")
print(result.final_output)
```

`Runner.run_sync` is sync. For async, `await Runner.run(...)`.

## Adding a tool

For the agent to do something, it needs tools. One decorator and the schema gets inferred.

```python
import asyncio
from agents import Agent, Runner, function_tool

@function_tool
def get_weather(city: str) -> str:
 return f"The weather in {city} is sunny."

agent = Agent(
 name="Weatherman",
 instructions="Only answer city weather questions.",
 tools=[get_weather],
)

async def main():
 result = await Runner.run(agent, "What's the weather in Tokyo?")
 print(result.final_output)

asyncio.run(main())
```

The loop inside is simple. Call the LLM → if the response contains tool calls, execute them → feed results back → return when there's a final output. Handoffs swap the active agent mid-loop.

## Memory via Session

Stitching history by hand every turn is tedious. Hand it to a session object and move on.

```python
from agents import Agent, Runner, SQLiteSession

agent = Agent(name="Assistant", instructions="Reply very concisely.")
session = SQLiteSession("conversation_123")

result = await Runner.run(agent, "What city is the Golden Gate Bridge in?", session=session)
print(result.final_output) # San Francisco

result = await Runner.run(agent, "What state is it in?", session=session)
print(result.final_output) # California
```

One file, persistent context. Shut the laptop, open it tomorrow, the thread survives. Underrated little feature.

## Multi-agent - a taste of Handoff

Classic pattern: a triage agent routes to a sales or support agent based on intent.

```python
from agents import Agent, Runner, handoff

sales = Agent(name="Sales", instructions="Answer pricing and quotes only.")
support = Agent(name="Support", instructions="Answer refunds and bugs only.")

triage = Agent(
 name="Triage",
 instructions="Read the question and hand off to the right team.",
 handoffs=[handoff(sales), handoff(support)],
)

result = Runner.run_sync(triage, "How do I get a refund?")
print(result.final_output)
```

The LLM makes the call. You design roles, not rules. That's the flavor of the Agents SDK.

## How much can you trust it

Guardrails attach on both input and output. Pydantic schemas for structured output are table stakes. Tracing is built in, so runs are inspectable in a dashboard out of the box. This is production-minded tooling.

Don't get cocky though. Throw too many tools at an agent and costs dance. Timeouts, max-step caps, schema validation - set them day one. Your future self says thanks.
