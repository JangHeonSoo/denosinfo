## What Is OpenClaw

One-line answer: a locally-executed, open-source personal AI agent.

It runs directly on your Mac, Windows, or Linux — no cloud dependency. The architecture places AI on top of messaging apps you already use: WhatsApp, Telegram, Slack, Discord, iMessage. It can read/write files, execute shell commands, and control browsers, while the ClawHub skills marketplace provides 4,000+ community-built extensions. The software itself is free; you pay only for your LLM API tokens (Claude, GPT-5, etc.).

## v2026.4.11 — Core Technical Breakdown

### ChatGPT Conversation Import + Memory Palace

A native ingestion pipeline now brings ChatGPT conversation history directly into OpenClaw's Dreaming tab. Imported conversations are organized into Imported Insights and Memory Palace diary subtabs, letting you browse compiled wiki pages and raw source pages from the UI. Users running GPT and OpenClaw in parallel now have a real history migration path.

### video_generate — Full Rebuild

The video generation tooling has been completely redesigned. The headline change is URL-only asset delivery — large video files no longer need to be loaded into memory, only the URL is passed through. This is joined by reference audio inputs, per-asset role hints, adaptive aspect-ratio support, and a higher image-input cap. Seedance 2.0 model references were already added in 2026.4.10 via the bundled fal provider.

### Microsoft Teams Reaction Support

Teams integration has finally reached practical territory. Graph API-based reaction add/list, Graph API pagination, and delegated OAuth setup all landed simultaneously. The architecture preserves existing application-auth read paths while using delegated auth for reaction sends. Using OpenClaw inside a corporate Teams environment is now a real option.

### Structured Chat Bubbles + [embed] Tag

Assistant media/reply/voice directives now render as structured chat bubbles. The new `[embed ...]` rich output tag was also added, with external embed URLs gated behind config for security.

## v2026.4.10 — Core Technical Breakdown

### Active Memory Plugin

The most-watched feature from 2026.4.10. A dedicated memory sub-agent runs just before the main reply, automatically pulling in preferences, context, and past details — no manual "remember this" prompts needed. You can inspect live memory behavior with `/verbose` and tune message/recent/full context modes via config. Official docs at `docs.openclaw.ai/concepts/active-memory`.

### Codex Provider — Independent Split

Codex models previously shared the OpenAI provider path. Now a standalone Codex provider handles managed auth, native threads, model discovery, and compaction independently. `openai/gpt-` stays on the OpenAI path; `codex/gpt-` routes through Codex. Coding-heavy workflows benefit from clean separation.

### Local MLX Talk Mode (Apple Silicon Only)

Talk Mode now supports fully local speech processing on Apple Silicon Macs — no cloud API calls, no voice data leaving the device. System voice fallback is included. Practical for privacy-sensitive environments or offline use cases.

## v2026.3.22 — The "Biggest Ever" Update Revisited

Released late March, v2026.3.22 remains the single largest OpenClaw release: 45+ new features, 13 breaking changes, 82 bug fixes, 20 security patches — earning 294 GitHub reactions.

### ClawHub Skills Marketplace Goes Native

`openclaw plugins install` now prioritizes ClawHub over npm, falling back to npm only when a package isn't found. Cross-ecosystem compatibility auto-converts skill packages from Claude, Codex, and Cursor into OpenClaw format — 4,000+ skills in one place.

### Agent Timeout: 10 minutes → 48 hours

The default agent timeout expanded from 10 minutes to 48 hours with zero config changes. Batch jobs, long documents, and complex multi-step workflows no longer get cut off mid-task.

### SSH/OpenShell Pluggable Sandbox

The sandbox execution environment now supports pluggable backends. SSH and OpenShell are the first two, with `mirror` and `remote` workspace modes. Agents can now SSH into remote machines and execute tasks directly — no more workarounds for server-side execution.

### Multi-LLM Provider Expansion

## ByteRover Native Memory Plugin — Notable Third-Party

Separate from the official Active Memory plugin, ByteRover's native memory plugin offers a three-layer memory architecture:

- Context Tree — deep structured knowledge base
- Workspace Memory — core rules, preferences, guidelines
- Daily Memory — session notes

It achieves 92.2% retrieval accuracy on the LoCoMo benchmark, maintaining 90% accuracy even with lightweight models. Installs via ClawHub; requires v2026.3.22+. Memory is stored as human-readable, git-diffable Markdown files — you can see exactly what the agent has learned.

```bash
openclaw skills install @byterover/byterover
```

The 48-hour timeout, SSH sandbox, ClawHub's 4,000+ skills, and Active Memory together form a competitive locally-run autonomous agent environment.
