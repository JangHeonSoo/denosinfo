## 1. MCP, 그게 뭔데

솔직히 말하면, LLM만으로는 할 수 있는 게 의외로 적다. 학습 시점 이후의 정보는 모르고, 파일 시스템도 건드리지 못하며, 외부 API는 꿈도 못 꾼다. MCP는 이 한계를 뚫는 표준 다리다.

정식 명칭은 Model Context Protocol. Anthropic이 2024년 11월에 공개했고, Claude뿐 아니라 ChatGPT, Cursor, GitHub Copilot 등 다양한 AI 앱에서 채택했다. "AI의 USB-C"라고 불리는 이유가 있다. 예전에는 AI 앱마다 외부 시스템 연동 방식을 따로 구현했는데, MCP가 생기면서 MCP 서버 하나만 만들면 어떤 AI 앱에서든 갖다 쓸 수 있게 됐다.

아래 한 문장이 전부다.

> MCP = LLM이 외부 도구·데이터에 접근하는 방법을 표준화한 프로토콜

![미래지향적인 광신호 커넥터가 정교한 포트에 연결되는 모습](/images/mcp_hero.png)

## 2. 구조: Host · Client · Server

MCP 아키텍처는 세 주체가 맞물려 돌아간다.

| 구성요소 | 역할 | 실제 예 |
|---|---|---|
| Host | 사용자와 대화하는 AI 앱. 여러 Client를 관리하고 보안 정책 적용 | Claude Desktop, Cursor, VS Code |
| Client | Host 안에서 특정 MCP Server와 1:1 연결. JSON-RPC 메시지 중계 | Claude 내부 MCP 모듈 |
| Server | 실제 도구(Tool), 데이터(Resource), 템플릿(Prompt)을 제공 | 날씨 서버, DB 서버, GitHub 서버 |

흐름은 이렇다.

```
사용자 → Host(LLM 판단) → Client → Server → 결과 반환 → Host → 사용자
```

예를 들어, Claude Desktop에게 "오늘 서울 날씨 알려줘"라고 하면, Host가 날씨 Tool이 필요하다고 판단하고 Client를 통해 날씨 MCP Server에 JSON-RPC 요청을 보낸다. 서버가 실제 API를 호출하고 결과를 돌려주면, Claude가 자연어로 답변한다. 이 과정을 사용자는 모른다. 그냥 답이 온다.

![Host, Client, Server의 유기적인 연결을 형상화한 디지털 네트워크 아키텍처 비주얼](/images/mcp_architecture.png)

## 3. 내부 통신: JSON-RPC 2.0

MCP는 내부적으로 JSON-RPC 2.0 포맷으로 통신한다. 요청 하나를 들여다보면:

```json
{
 "jsonrpc": "2.0",
 "id": 1,
 "method": "tools/call",
 "params": {
 "name": "get_weather",
 "arguments": { "city": "Seoul" }
 }
}
```

응답은 이렇게 온다.

```json
{
 "jsonrpc": "2.0",
 "id": 1,
 "result": {
 "content": [{ "type": "text", "text": "서울 현재 기온: 18°C, 맑음" }],
 "isError": false
 }
}
```

전송 방식은 크게 두 가지다.

- Stdio(표준 입출력): 로컬 프로세스 간 통신. 속도 빠르고 설정 간단. 개발·테스트에 적합.
- Streamable HTTP: 원격 서버와 통신. 실시간 스트리밍 지원. 운영 환경에 적합.

## 4. MCP 서버의 3가지 핵심 기능

MCP Server가 제공할 수 있는 것은 딱 세 가지다.

Tools — AI가 직접 호출하는 함수. "두 수를 더해줘", "날씨 검색해줘" 같은 것. 가장 많이 쓰인다.

Resources — 읽기 전용 데이터. 파일 내용, DB 레코드, API 응답 같은 정적 컨텍스트를 LLM에 넘긴다.

Prompts — 재사용 가능한 프롬프트 템플릿. "다음 할 일 제안해줘" 같은 패턴을 서버에서 관리한다.

## 5. 직접 만들어보자 — FastMCP로 10분 안에

설치부터 실행까지. 복잡하지 않다.

### 5-1. 환경 준비

```bash
pip install mcp fastmcp
```

Python 3.10 이상이 필요하다. `fastmcp`는 MCP 공식 Python SDK가 제공하는 고수준 래퍼로, 데코레이터 하나로 Tool을 등록할 수 있다.

### 5-2. MCP 서버 작성 (`server.py`)

두 수를 더하는 Tool과 날씨 정보를 돌려주는 Tool, 두 개를 만든다.

```python
# server.py
from mcp.server.fastmcp import FastMCP

# 서버 인스턴스 생성
mcp = FastMCP("my-first-mcp")

@mcp.tool()
def add(a: int, b: int) -> int:
 """두 정수를 더한다."""
 return a + b

@mcp.tool()
def get_weather(city: str) -> str:
 """도시 이름을 받아 날씨 정보를 반환한다. (데모용 하드코딩)"""
 weather_data = {
 "Seoul": "18°C, 맑음",
 "Busan": "22°C, 흐림",
 "Jeju": "25°C, 구름 조금",
 }
 return weather_data.get(city, f"{city}의 날씨 정보를 찾을 수 없다.")

if name == "main":
 mcp.run(transport="stdio")
```

데코레이터 `@mcp.tool()` 하나면 끝이다. 함수 docstring이 Tool 설명이 된다. LLM이 이 설명을 보고 언제 어떤 Tool을 쓸지 판단한다.

### 5-3. MCP 클라이언트 작성 (`client.py`)

서버에 연결해서 Tool 목록을 확인하고, 실제로 호출해보는 클라이언트다.

```python
# client.py
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
 # 서버 실행 파라미터 설정
 server_params = StdioServerParameters(
 command="python",
 args=["server.py"],
 env=None
 )

 async with stdioclient(serverparams) as (read, write):
 async with ClientSession(read, write) as session:
 # 세션 초기화
 await session.initialize()

 # 등록된 Tool 목록 확인
 toolsresponse = await session.listtools()
 print("=== 사용 가능한 Tools ===")
 for tool in tools_response.tools:
 print(f" - {tool.name}: {tool.description}")

 # add Tool 호출
 print("\n=== add(3, 7) 호출 ===")
 result = await session.call_tool("add", {"a": 3, "b": 7})
 print(f" 결과: {result.content[0].text}")

 # get_weather Tool 호출
 print("\n=== get_weather('Seoul') 호출 ===")
 result = await session.calltool("getweather", {"city": "Seoul"})
 print(f" 결과: {result.content[0].text}")

if name == "main":
 asyncio.run(main())
```

### 5-4. 실행

```bash
python client.py
```

출력 결과:

```
=== 사용 가능한 Tools ===
 - add: 두 정수를 더한다.
 - get_weather: 도시 이름을 받아 날씨 정보를 반환한다. (데모용 하드코딩)

=== add(3, 7) 호출 ===
 결과: 10

=== get_weather('Seoul') 호출 ===
 결과: 18°C, 맑음
```

서버-클라이언트가 Stdio를 통해 JSON-RPC로 대화한 결과다. 실제 Claude Desktop이나 Cursor와 연결하면 AI가 이 Tool들을 자율적으로 판단해서 쓴다.

## 6. MCP Inspector로 시각적으로 테스트하기

코드 말고 GUI로 확인하고 싶다면 MCP Inspector를 쓴다.

```bash
npx @modelcontextprotocol/inspector python server.py
```

`http://127.0.0.1:6274`가 열린다. 브라우저에서 Tool을 클릭하고, 파라미터를 입력하고, 결과를 바로 확인할 수 있다. API 개발할 때 Postman 쓰는 느낌이다.

## 7. Claude Desktop에 연결하기

만든 서버를 Claude Desktop에 붙이려면 설정 파일 하나만 수정하면 된다.

macOS: `~/Library/Application Support/Claude/claudedesktopconfig.json` 
Windows: `%APPDATA%\Claude\claudedesktopconfig.json`

```json
{
 "mcpServers": {
 "my-first-mcp": {
 "command": "python",
 "args": ["/절대경로/server.py"]
 }
 }
}
```

저장하고 Claude Desktop을 재시작하면 Tools 아이콘이 뜬다. "3 더하기 7이 뭐야?"라고 물어보면 Claude가 스스로 `add` Tool을 호출한다.

## 8. 여기서 더 나아가려면

| 단계 | 할 것 | 키워드 |
|---|---|---|
| 1단계 | 실제 외부 API 연동 | `httpx`, `requests` |
| 2단계 | Resource로 파일 시스템 노출 | `@mcp.resource()` |
| 3단계 | Streamable HTTP로 원격 배포 | `transport="http"` |
| 4단계 | 인증 추가 | OAuth, Bearer Token |
| 5단계 | 기존 FastAPI 앱을 MCP로 | `fastapi-mcp` 라이브러리 |

MCP 생태계는 2025년부터 폭발적으로 성장 중이다. Slack, GitHub, Notion, PostgreSQL 등 수백 개의 공개 MCP 서버가 이미 존재한다. 바퀴를 새로 발명할 필요가 없다. 하지만 직접 만들어봐야 남의 것도 읽힌다.
