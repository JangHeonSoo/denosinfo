코딩 방식이 바뀌고 있다. 빠르게. GitHub Stars 58,200개, 다운로드 110만 건을 돌파한 오픈소스 코딩 에이전트 Cline이 VSCode 생태계 안에서 조용히 판도를 흔들고 있다. 정작 많은 개발자들은 Cursor나 Windsurf 같은 독립형 IDE만 쳐다보고 있다. 진짜 강자를 모르고 있는 것일까.

---

## Cline이 뭔데

Cline은 VSCode 확장 프로그램이다. 그냥 코드 제안 도구가 아니다. 파일을 만들고, 터미널 명령을 실행하고, 브라우저를 열어서 직접 클릭까지 한다. 사람이 하는 개발 행위 자체를 에이전트가 대신 수행하는 구조다.

2024년 7월에 출시됐고, Apache 2.0 라이선스로 완전히 열려 있다. 포크도 자유롭게 가능하고, 실제로 Roo Code(GitHub Stars 10k, 다운로드 300K 이상)와 Kilo Code 같은 파생 도구들이 속속 등장했다. 오픈소스 생태계가 이미 증명해주고 있다.

핵심은 BYOK(Bring Your Own Key) 모델이다. OpenAI, Anthropic, DeepSeek, 심지어 로컬 LLM까지 직접 API 키를 꽂아서 쓴다. 플랫폼 구독료 없이 쓴 만큼만 낸다. OpenRouter 경유 시 5% 마크업이 붙지만, 기본 구조는 완전히 BYOK다.

## 핵심 기능 5가지

Plan/Act 이중 모드가 Cline의 첫 번째 차별점이다. Plan 모드에서 AI가 실행 계획 전체를 먼저 보여주고, Act 모드에서 실제로 코드를 짜고 파일을 수정한다. "일단 해봐" 식의 눈먼 실행을 막아준다.

터미널 자율 실행도 빼놓을 수 없다. VSCode v1.93의 Shell Integration API를 활용해서, 패키지 설치부터 배포 스크립트 실행, 데이터베이스 마이그레이션까지 직접 돌린다. 백그라운드 프로세스도 모니터링한다.

브라우저 자동화는 Claude 3.5 Sonnet의 Computer Use 기능을 연결한 것이다. 실제로 Chrome을 열고, 버튼 클릭, 스크롤, 텍스트 입력을 직접 수행한다. 런타임 에러를 확인하고 UI 버그를 스스로 수정한다.

MCP(Model Context Protocol) 지원은 Cline의 확장성을 무한대로 넓혀준다. 내부 모니터링 시스템 연결, 커스텀 보안 스캔, 자동 문서화 파이프라인까지 JSON 기반 API로 직접 만들어 붙일 수 있다.

마지막으로 Checkpoint 시스템이다. AI가 작업할 때마다 자동으로 워크스페이스 상태를 스냅샷으로 저장한다. 브라우저 세션과 터미널 상태까지 함께 보존된다. 일반 Git 커밋보다 훨씬 세밀한 롤백이 가능하다.

## 경쟁 도구들과 나란히 세워보면

### Cursor: 빠르고 세련됐지만 비싸다

Cursor는 VS Code를 통째로 포크해서 만든 독립형 IDE다. 코드 자동완성 속도만큼은 현재 도구 중에서 가장 빠르다는 평이 많다. Composer Mode로 프로젝트 전체를 맥락으로 잡아두고 대규모 리팩토링도 가능하다.

가격은 월 \$20. 하지만 함정이 있다. 프리미엄 모델(Claude 3.5 Sonnet/GPT-4o) 요청이 월 500회로 제한된다. 하루 8시간 풀로 개발하는 개발자라면 1주일이면 바닥난다. 초과하면 느린 모델로 강제 다운그레이드된다.

### Windsurf: 바이브코딩 경험은 최고

Windsurf는 Codeium이 만든 또 다른 VS Code 포크다. 인터페이스의 매끄러움은 셋 중 가장 뛰어나다. Cascade라는 멀티스텝 컨텍스트 엔진이 대규모 코드베이스 리팩토링에서 진가를 발휘한다.

월 \$15로 Cursor보다 저렴하고, "Turbo" 모드로 터미널 명령 연속 실행도 가능하다. 스크린샷 드래그앤드롭 하나로 UI를 뚝딱 만들어주는 경험은 타 도구와 비교해 독보적이다. 다만 "Flow Action Credits" 과금 방식이 복잡하고, 고강도 에이전트 사용 시 빠르게 소진된다.

### GitHub Copilot: 넓게, 그러나 얕게

GitHub Copilot은 월 \$10으로 가장 저렴하고, VS Code부터 JetBrains, Neovim까지 IDE 지원 범위가 가장 넓다. Microsoft가 뒤를 받치고 있어 안정성과 신뢰도는 높다.

그런데 자율성이 낮다. PR 자동 요약, 커밋 메시지 생성 같은 GitHub 통합 기능은 훌륭하지만, "파일 50개 동시에 고쳐줘" 같은 자율적 에이전트 작업은 Cline 대비 한계가 명확하다.

### Bolt.new / Lovable / v0: 다른 종류의 도구

이 세 가지는 비교 대상이 약간 다르다. 코드를 모르는 사람도 자연어 한 줄로 앱을 만들어주는 브라우저 기반 바이브코딩 플랫폼이다. 설치가 없고, 배포까지 원클릭이다.

Bolt.new는 속도가 빠르고 풀스택 개발에 강하다. 월 \$20에 1천만 토큰을 제공한다. Lovable은 비개발자가 가장 다루기 쉽고, \$200M 투자를 받아 급성장 중이다. v0는 Vercel이 만든 것답게 React 컴포넌트 UI 품질이 최고 수준이다.

Cline과의 차이는 분명하다. 이 도구들은 프로토타입을 빠르게 뽑는 데 최적화됐고, Cline은 이미 존재하는 프로덕션 코드베이스에서 복잡한 작업을 자율적으로 처리하는 데 강하다.

## 가격 현실

| 도구 | 기본 요금 | 과금 방식 | 모델 선택권 |
|------|---------|---------|-----------|
| Cline | 무료 | BYOK (토큰 사용량) | 완전 자유 |
| Cursor | \$20/월 | 정액 + 초과 과금 | 제한적 |
| Windsurf | \$15/월 | Credits 소진 | 제한적 |
| GitHub Copilot | \$10/월 | 정액 | 없음 |
| Bolt.new | \$20/월 | 토큰 소진 | 없음 |
| Lovable | \$20/월 | 크레딧 소진 | 없음 |
| v0 | \$20/월 | 크레딧 소진 | 없음 |

Cline에서 DeepSeek V3를 쓰면 입력 토큰 1백만 개당 \$0.32다. Claude Sonnet 4.5는 \$3.00/백만 토큰. 가벼운 작업은 DeepSeek, 복잡한 코드 생성은 Claude로 직접 선택하면 된다. Cursor의 \$20 정액제가 사실은 더 비쌀 수 있다.

## 누가 뭘 써야 하는가

Cline은 이미 개발 환경이 갖춰진 개발자, 보안 때문에 코드를 외부 SaaS에 올리기 싫은 기업, 로컬 LLM으로 오프라인 작업이 필요한 케이스에 최적이다. 초기 API 키 설정이 귀찮지만, 그 뒤로는 어떤 도구보다 강력하다.

Cursor는 매일 VS Code처럼 쓰면서 AI 자동완성과 빠른 편집을 원하는 개발자에게 맞다. 특히 Tab 키 워크플로우를 좋아하는 사람. 다만 대규모 자율 작업은 Cline이 더 낫다.

Windsurf는 스타트업이나 MVP를 빠르게 만들어야 하는 팀에 어울린다. 비용 대비 바이브코딩 경험이 가장 좋다.

Bolt.new/Lovable/v0는 코드를 안 써도 되고, 빠른 프로토타입이 목적이면 고민 없이 쓰면 된다. 단, 프로덕션 수준의 복잡한 코드베이스 관리는 한계가 있다.

## Cline이 조용히 이기고 있는 이유

오픈소스라는 특성이 낳는 이점이 실질적이다. 수백 명의 컨트리뷰터가 코드를 개선하고, 수천 명이 Discord에서 프롬프트 최적화 방법을 공유한다. DeepSeek R1 같은 저렴한 고성능 모델이 나올 때마다, Cline 사용자는 즉시 갈아탈 수 있다. Cursor는 모델을 직접 선택하지 못한다.

Cursor가 플랫 피 구독료 안에서 AI 제공업체에 지불하는 비용과 사용자에게 받는 금액 사이의 괴리로 고민하는 동안, Cline은 그 구조적 딜레마 자체에서 자유롭다. 쓴 만큼 낸다. 남은 크레딧 걱정이 없다.

메모리 뱅크 기능도 Cursor보다 먼저 도입했다. 프로젝트별 `.clinerules` 파일로 아키텍처 규칙과 코딩 표준을 강제할 수도 있다. 판 위의 말들을 제대로 세팅해두면, Cline은 50~100단계짜리 자율 루프를 혼자 돌린다.

싸지는 않다. 그러나 결국 더 비싸지도 않다. 그리고 이 도구는 계속 발전한다.
